# Standalone Movie World Android port

- Use Kotlin and Compose with the existing SQLite catalogue bundled and queried read-only. Keep IDs stable. Replace catalogue versions independently of user data. Match genre and IMDb sorting, title and actor search, year filters, details, cast and Adult exclusion. Cache artwork and show offline placeholders.
- Store favourites, resume points, renderer and download state in a separate Room database. Keep UI preferences in DataStore. Preserve Continue Watching, Resume and Start Over from renderer-reported position. Start with fresh Android state.
- Open in Telegram hands the original post URL to Android with browser fallback. It works away from the PC over mobile data. Casting uses separate TDLib authentication with a channel member account. Resolve the exact movie post, download to private storage, and protect session encryption with Android Keystore.
- Prove phone-hosted playback on the Samsung RU7100 before building out casting. Discover via SSDP with manual description URL fallback and identify the TV by renderer ID. Use UPnP AVTransport and a temporary Wi-Fi HTTP listener with expiring opaque URLs, HEAD and byte-range support. Confirm playback from renderer status. Support pause, resume, stop and verified seek.
- Use a notification-backed foreground service and SDK-appropriate LAN permissions. Allow one active job, bounded cache, cancellation and retry. Save progress and recover interrupted state. Download the entire file first and serve TV-compatible formats as-is. Offer Telegram for unsupported media.
- Verify a known-compatible MP4 and a private Telegram movie on the Samsung with the PC off and phone locked. Check offline catalogue parity and upgrades, Telegram over mobile data, retry and resume, permission denial, network loss, unsupported files and low storage. Deliver a signed APK and setup instructions.
- Defer transcoding, a phone video player, cloud sync and remote TV control. Keep the existing PC app independently usable.
